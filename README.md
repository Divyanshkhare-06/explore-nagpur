## 🚀 Quick Start (Run Locally)

1. Clone the repository:
   ```bash
   git clone https://github.com/Divyanshkhare-06/explore-nagpur.git
   cd explore-nagpur/uiux
   ```
2. Start a local server:
   ```bash
   python -m http.server 8000
   ```
3. Open in your browser:
   ```text
   http://localhost:8000
   ```

## 🌐 GitHub Pages Deployment

The repository is configured for immediate GitHub Pages deployment:
1. Go to repository **Settings** &rarr; **Pages**.
2. Select **Source:** Deploy from a branch (`main`, `/ root`).
3. The site is live at:
   ```text
   https://divyanshkhare-06.github.io/explore-nagpur/uiux/
   ```
